# Project conventions

- **Version bump:** every time you change project code, bump `APP_VERSION` in
  `main.py` before finishing. The version is also shown in the app-bar header
  (`v{{ app_version }}`).
- do not use underscores in functions prefixes/postfixes
- for random code changes write short Petre I speech in comments
